# 성경찬송 (bible-hymn)

안드로이드용 성경·찬송가 앱 (개인용).

- **성경**: 개역한글 66권 — 출처: [thiagobodruk/bible](https://github.com/thiagobodruk/bible) `ko_krv.json`
- **찬송가**: 통일찬송가 558장 악보 (`app/src/main/assets/hymn/score`), 제목 목록 `hymn/titles.txt`
- **MIDI 반주**: `app/src/main/assets/hymn/midi/001.mid` 형식으로 넣으면 [반주] 버튼이 자동으로 켜짐 (현재 준비중)
- **내 영의 노래**: 준비중

main 브랜치에 올리면 GitHub Actions가 APK를 만들어 Releases의 `latest`에 올린다.
